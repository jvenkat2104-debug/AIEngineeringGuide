# Make your project reproducible

Status: Draft | Independent review pending
Official sources checked: 12 November 2026

Record versions you actually tested. Follow your course or project’s compatibility requirements and isolate dependencies using its supported environment method.

## Before sharing

- Record language/interpreter, operating system where relevant and dependency versions.
- Include setup/run instructions, sample inputs and expected outputs.
- State checks actually performed and remaining limitations.
- Explain required configuration without committing credentials.
- Ask a peer to follow the instructions in a fresh environment where possible.

A release announcement does not prove your own project works with that version.

## Dated Python security note

On **12 November 2026**, the [official Python downloads page](https://www.python.org/downloads/) displays an emSign certificate security notice linking to [Python’s incident guidance](https://discuss.python.org/t/information-for-python-users-regarding-emudhra-emsign-ca-certificate-security-incident/109576).

The guidance calls for updates to affected tooling and explains that existing environments need attention. Follow its current remediation instructions for your installation or ask your college/lab administrator. Do not disable certificate verification to work around failures. This guide has not inspected or patched your machine.

The downloads page lists Python 3.15.2 dated 25 October 2026. Check supported-series security fixes and dependency compatibility rather than upgrading merely for new features.
