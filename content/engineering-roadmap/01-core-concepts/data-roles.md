# Data roles explained

**Level: Intermediate** · Start with the Year 1 roadmap if these ideas are unfamiliar.

Status: Draft | Independent review pending

Think of a water system: engineers construct the pipes, operators read the meters, and analysts investigate patterns. Data work also contains different responsibilities.

| Role | Main question | Typical work | Foundations to explore |
| --- | --- | --- | --- |
| Data analyst | What happened? | Clean records, summarise results, build reports | Spreadsheets, SQL, statistics, communication |
| Data engineer | How does reliable data arrive? | Build and maintain collection and transformation pipelines | SQL, programming, storage, testing |
| Data scientist | What explains a pattern and what might happen next? | Experiments, statistical analysis and modelling | Statistics, mathematics, programming |
| ML engineer | How does a model work reliably in a product? | Deployment, evaluation, monitoring and updates | Software engineering and machine learning |

Titles overlap. Read the responsibilities and eligibility of an actual role instead of assuming a degree title guarantees access.

## Try all four perspectives

Use a small invented canteen-sales table. Summarise daily demand, describe how records should be collected, predict demand using an average, and explain how you would detect an unreliable prediction. Record missing data and assumptions before drawing conclusions.
