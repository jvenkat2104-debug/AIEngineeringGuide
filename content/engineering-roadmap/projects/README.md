# Choose a manageable project

Status: Draft | Independent review pending

| Stage | Project | What to show |
| --- | --- | --- |
| Beginner | Task list or library borrowing logic | Inputs, saved records and error behaviour |
| Beginner | Sensor simulation | Diagram, units and sample readings |
| Beginner | Algorithm experiment | Inputs, correctness checks and running-time plot |
| Developing | Canteen demand analysis | Data cleaning, baseline and prediction error |
| Developing | Digital counter | State diagram, tests and waveforms |
| Advanced | Sensor-to-cloud design | Authentication, replay tests and delivery assumptions |

Start with [first-project guidance](../00-start-here/year-1-habits.md). Find the [counter exercise](../04-growth-careers/chip-design.md), [data-role exercise](../01-core-concepts/data-roles.md) or [advanced telemetry design](../05-technical-grinding/edge-and-cloud-core.md).

For Mechanical and Civil, use faculty-reviewed design or observation activities. A student exercise is not a certified engineering design. Each result should include assumptions, verification and limits.
