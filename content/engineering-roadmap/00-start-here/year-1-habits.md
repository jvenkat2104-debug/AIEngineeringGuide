# Year 1 habits and your first project

Status: Draft | Independent review pending

## Study by building

After a topic, choose something small to calculate, sketch, simulate or build. Keep notes in your own words. Redo a solved problem later without looking, and explain one concept to a friend each week. Use your college library and subject documentation alongside tutorials.

## Use AI as a tutor

Ask for a hint, a simpler explanation or a question that tests your understanding. Check important answers against textbooks or official documentation. Read and run code you accept. Follow your college’s assignment rules and submit only work you can explain.

## Finish a small project in two to four weeks

| Path | A manageable first result |
| --- | --- |
| Computing | A task list; start with a simple interface, then add saved data |
| ECE/EE | A simulated or supervised low-voltage sensor reading shown on screen |
| Mathematics and Computing | Implement an algorithm and plot how running time changes |
| Mechanical | A sketch or CAD model of a simple mechanism with force and material assumptions |
| Civil | A drainage observation map with measurements and questions, not a construction design |

Mechanical and Civil examples are editorial additions requiring branch review. Start smaller if equipment or computing access is limited.

## Definition of finished

- State the problem and what you deliberately left out.
- Include instructions, inputs and a sample result.
- Record one failure, how you investigated it and what you changed.
- Explain the main decisions without reading generated text.
- Keep a project folder or repository; publish only material you have the right to share.

A complete small result is more useful for reflection than a large unfinished tutorial copy.
