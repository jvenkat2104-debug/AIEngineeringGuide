# Contributing

This project is an early draft. Start with an issue describing a confusing section, correction or proposed module. Pull requests are welcome for review; no response-time commitment is currently made.

Include the section, proposed change, reason, sources where relevant, and review date. Use plain language and define technical terms. Label personal experience and disclose relevant affiliations. Never include private student data, confidential employer material, copied course content, leaked papers, promotions or referral links.

Use the [module template](templates/module.md). Mark material Draft until a qualified reviewer actually checks it. Code examples need setup instructions, tested versions and meaningful verification. Be respectful of beginners and avoid branch or college stereotypes.

Licensing is pending; contributors must own or have permission to share proposed material. Maintainers should settle contribution licensing before accepting external content for release.
